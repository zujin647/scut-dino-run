# 华工快跑

华南理工大学校园主题跑酷游戏。华南理工大学校徽作为主角，木棉树作为主要障碍，远景包含逸夫科技馆、图书馆、六号楼和正门刻石等校园地标。

## 本地运行

```powershell
npm start
```

浏览器打开 `http://localhost:4173`。终端同时会输出局域网地址，同一网络内的手机或电脑可以直接访问。

## 验证

```powershell
npm run check
```

游戏不依赖第三方包，也不需要后端服务。整个目录可以直接上传到 GitHub Pages、Cloudflare Pages、Netlify 或任意静态网站托管服务。

仓库已包含 GitHub Pages 自动发布工作流。推送到 `main` 分支后，Actions 会验证并发布静态站点。

## 操作

- 空格、向上键、轻触画面或“跳跃”按钮：跳跃
- 向下键或按住“低头”按钮：低头
- 页面失去焦点时自动暂停
