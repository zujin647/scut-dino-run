# Credits

## Game code and illustration

The game engine, interface, pixel-style campus illustrations, kapok tree obstacles, and blue magpie artwork are original work created for this project.

## University identity

The player character uses the South China University of Technology logo introduced in 2022. The source SVG was published in the university's 2023 international-student handbook and uploaded to Wikipedia under a non-free media rationale.

- https://zh.wikipedia.org/wiki/File:South_China_University_of_Technology_Logo_(Since_2022).svg
- https://www2.scut.edu.cn/sie_cn/2023/0830/c5029a517105/page.htm

The logo and university name remain the property of South China University of Technology. This project is an unofficial campus-themed interactive work. Confirm the university's current identity usage requirements before public, commercial, or official event distribution.
